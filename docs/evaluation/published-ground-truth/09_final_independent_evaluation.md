## 2. Attack Detection Performance

### The Attack Context
CTU IoT-23 Capture 48-1 captures a physical Raspberry Pi device (`192.168.1.200`) infected with Mirai botnet malware over a duration of 9.77 hours. The infection lifecycle comprises:
1. **Initial C&C Payload Ingestion**: 11 cleartext HTTP connections to `167.99.182.238:80` downloading ELF executable binaries.
2. **Aggressive Propagation & Horizontal Scanning**: 3,386,119 TCP SYN probe flows targeting port 23 (Telnet) across the global IPv4 address space.
3. **C&C Beacons & Periodic Coordination**: 1,722 command-and-control connection attempts.

### NetGuard Detection Coverage
NetGuard's behavioral rules detected the horizontal port scanning campaign with near-perfect precision:
- **`PORT_SCAN`**: 3,473 alerts (detecting bursts of $\ge 30$ SYN targets within 10 seconds).
- **`SLOW_PORT_SCAN`**: 292 alerts (detecting low-and-slow horizontal probing over 120-second sliding windows).
- **`ARP_SPOOF`**: 262 alerts (identifying initial MAC-address binding updates between the device and gateway `192.168.1.1`).

Every port scan alert generated by NetGuard mapped directly to official publisher ground-truth flows labeled `Malicious | PartOfAHorizontalPortScan`.

## 4. Suricata 8.0.7 Comparative Baseline

Suricata 8.0.7 was executed on the identical 13.56M-packet PCAP under the standard Emerging Threats (ET) Open ruleset (53,391 signatures):
- **Suricata Alerts**: **85** total alerts.
- **Top Detection**: Suricata fired 22 alerts on the HTTP dropper download (`ET INFO Executable and linking format (ELF) file download Over HTTP`), successfully detecting the initial binary delivery.
- **Detection Gap**: Suricata fired **zero alerts** for the 3,386,119 TCP SYN probe flows because the standard ET Open ruleset lacks default horizontal SYN scanning heuristics for unestablished TCP connections.
- **Engine Comparison**: NetGuard provided continuous visibility into the botnet's network propagation (3,765 alerts covering 3.38M scan flows), whereas Suricata detected the application-layer executable download. The two systems provide complementary coverage across the transport and application layers.
